🎯 О проекте

🛰️

Спутниковые данные

Анализ биомассы ESA CCI, снимков Sentinel-2, потерь древесного покрова GFC и продукта гарей MODIS.

📊

Расчёт запаса углерода

Метод разности запасов с переводом биомассы в углерод (CF = 0.47) и в CO₂-эквивалент (44/12).

📉

Оценка неопределённости

Сценарный диапазон результата, границы L и U, учёт ошибок входных данных.

🌱

Углеродные единицы

Сравнение с базовой линией, вычет за неопределённость и резерв, расчёт Q потенциальных единиц.

💰

Доход по трём сценариям

Пессимистичный, базовый и оптимистичный прогноз дохода от продажи углеродных единиц.

🗺️

Карта и динамика

Спутниковая карта участка, график изменения углерода по годам, события (пожары, потери).

🚀 Как запустить локально

1

Открой PowerShell от имени администратора

Нажми Win + X и выбери «Терминал (Администратор)».

2

Скачай ZIP и распакуй

На странице GitHub нажми Code → Download ZIP и распакуй в удобную папку.

3

Перейди в папку проекта

Скопируй путь через проводник (правой кнопкой по адресной строке → «Копировать адрес как текст») и выполни:

cd "путь к распакованной папке"
4

Активируй виртуальное окружение

.\venv\Scripts\Activate.ps1

В начале строки появится (venv) — значит всё работает.

Если venv отсутствует — создай вручную:

python -m venv venv .\venv\Scripts\Activate.ps1 pip install -r requirements.txt
5

Запусти программу

streamlit run app.py

Через 2–3 секунды откроется браузер на http://localhost:8501.

6

Готово! 🎉

Выбери локацию, период и нажми «Анализировать» — увидишь карту, графики, расчёт единиц и доход.
